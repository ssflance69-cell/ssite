## 🌐 How to Upload to Hostinger

1. Log in to your **Hostinger hPanel** (`hpanel.hostinger.com`).
2. Go to **Websites** &rarr; **Manage** &rarr; **File Manager**.
3. Open **`public_html`**.
4. **Delete the default placeholder file** (`default.php`).
5. Upload everything inside this folder:
   - `index.html`
   - `index.php`
   - `assets/` folder
6. Refresh your domain URL—your corporate site is live!
